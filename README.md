## 🚀 Projetos em destaque

### 🖥️ Pre-Live — Compartilhamento de Tela em Tempo Real

Aplicativo desktop para Windows desenvolvido para compartilhar telas entre computadores por meio de salas privadas.

**Principais funcionalidades:**
- Compartilhamento de monitores e janelas
- Comunicação em tempo real utilizando WebRTC
- Salas privadas com convites por link ou código
- Gerenciamento de participantes e permissões
- Modos Simples e Estúdio
- Interface desktop e instalador para Windows

**Tecnologias:** TypeScript, Tauri 2, Rust, Node.js e WebRTC.

🌐 [Conhecer o Pre-Live](https://gust4d3str0.github.io/pre-live/)

---

### 🎲 Ascenção RPG — Sistema Web de Gerenciamento de Personagens

Aplicação web para criação e gerenciamento de fichas de personagens de RPG, com recursos específicos para jogadores e mestres.

**Principais funcionalidades:**
- Autenticação e gerenciamento de usuários
- Armazenamento de fichas em banco de dados
- Controle de acesso às informações
- Painel exclusivo para o mestre
- Importação de dados de planilhas Excel
- Interface responsiva e suporte a PWA

**Tecnologias:** JavaScript, Vite, Supabase e PostgreSQL.

🌐 [Acessar aplicação](https://ascencao-rpg.vercel.app/)

---

### 🤖 Chatbot Adaptativo com Reconhecimento Emocional

Projeto de Trabalho de Conclusão de Curso voltado à pesquisa e ao desenvolvimento de um chatbot de apoio emocional não clínico.

**Principais funcionalidades:**
- Interação por texto e voz
- Processamento e transcrição de áudio
- Reconhecimento de emoções na fala
- Integração com modelos de Inteligência Artificial
- Geração de respostas contextualizadas
- Arquitetura modular e testes automatizados

**Tecnologias:** Python, FastAPI, processamento de áudio, Machine Learning e modelos de linguagem.

📌 Projeto acadêmico em desenvolvimento e aprimoramento contínuo.

### 💧 HydroPulseAI — Monitoramento Hidráulico com IA

Sistema desenvolvido para explorar a aplicação de Inteligência Artificial na análise e previsão de possíveis falhas em sistemas hidráulicos.

O projeto utiliza dados simulados para apoiar análises, identificar padrões e gerar relatórios relacionados aos componentes monitorados.

**Áreas exploradas:** Desenvolvimento web, análise de dados, Machine Learning e aplicações de engenharia.
